## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/NomaanKilledar/nomaan-portfolio.git
   ```

2. Enter the project directory:

   ```bash
   cd nomaan-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000).

### Production Build

```bash
npm run build
```
